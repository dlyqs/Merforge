# 组织任务与本人上下文验收

本剧本对应 [WorkGraph 计划](organization-workgraph-plan.md)内部 Phase 7–8。工程验证不代表真实三机或 macOS/Windows 可见验收通过；这些检查由用户选择时间执行，不恢复此前取消的安装验收。

## 设备与权限准备

| 设备 | 账号与用途 | 必要权限 |
| --- | --- | --- |
| A | 组织服务机；管理员负责项目登记与授权 | 管理身份不自动拥有项目或任务正文读取权 |
| B | 领导账号；创建、修改计划 | 项目 read/write；创建计划后自动取得该计划根子树 read/edit |
| C | 员工账号；读取准备材料 | 项目 read，并另授任务 node 或 subtree read |

使用同一 Wi-Fi，按[组织基础剧本](organization-foundation-acceptance.md)核对地址、防火墙与完整证书指纹。A 显式启用服务，生成 B/C 的邀请；每台设备分别注册、登录、选择组织。不要共享账号或复制个人目录。

A 登记一个共享项目，记录创建回执中的项目 ID。在项目授权页给 B 项目读写、给 C 项目读取。A 若也要读取正文，须单独授予自己的项目和任务权限。准备第二个组织和一个无任务授权账号，用于切换与隔离检查。

## 单任务路径

1. B 从侧栏打开组织工作台 → 项目 → 查看任务。新项目尚无获准任务时可以创建单任务计划；不能因任务读取失败退出当前组织。
2. 创建任务，填写目标、范围、逐行验收要求和产物要求；建议责任人可填写 C 的成员 ID。保存后应看到版本 1 和“尚未下发，仅准备材料”。建议责任人不会自动获得任务权限。
3. C 搜索任务，应无法读取该任务；项目 read 不等于任务 read。B 展开任务标识，把计划 ID 和任务 ID 提供给 A。
4. A 在项目授权页填项目 ID，在独立任务授权区填计划 ID、任务 ID、C 成员与 node/subtree 范围，授予读取。即使 A 无正文读取权，也可读取授权元数据；元数据不含任务正文。
5. C 刷新搜索，打开任务。核对目标、范围、版本、建议责任人、必要性、前置说明和验收要求。下发人显示尚未下发；不应出现运行、完成或批准按钮。
6. B 读取完整计划并编辑，保存版本 2。C 刷新后看到新版本。局部授权的 C 不能读取整份计划编辑，也不能用裁剪视图覆盖计划。
7. C 打开“本人只读上下文”，核对保存版本及只读说明。关闭并重新打开应复用本人同任务绑定。另一个账号在同机打开同任务，应有独立绑定；本机重启后重新登录、在线核权后仍可重开。不同设备不做 Session 同步。
8. B 再修改任务。C 重开已绑定上下文，仍显示首次记录的准确版本；任务详情展示当前版本。上下文不能发送消息、调用工具、移动到个人空间或成为普通个人会话。

## 失败与隔离

- 保存失败：本地草稿与相同内容的重试标识保留在当前工作台；失效后先在线重验才显示旧草稿。网络结果不明时先查询未确认操作回执，不自动重放写入。关闭工作台、切换身份或退出不会持久保存草稿。
- 两台设备同时编辑同一版本：一方保存成功后，另一方必须收到冲突。旧草稿不能覆盖远端；用户放弃旧草稿，刷新并重新编辑确认。
- 撤销 C 的任务读取：已显示内容和在途结果失效，后续读取与本人上下文重开拒绝。撤销项目 read 同样拒绝任务和上下文读取。
- 断开服务或 Wi-Fi：显示连接不可用，组织任务正文与上下文不能离线打开；重连后须刷新核权。不要把已经合法取得的本机历史误称为能远程擦除。
- 切换账号、组织或个人视角：旧任务详情、草稿与上下文不应留在新视角；迟到响应不得重新显示。个人 Project/Bot 入口及原有对话仍正常。
- 无正文授权的管理员：只能管理 ID 与授权，不得通过搜索、历史、管理快照或授权区读到正文。
- 键盘检查：Tab 可到达搜索、任务行、编辑字段、授权和上下文按钮；Escape 可关闭对话框。分别检查窄窗口、长文本、中英文及 macOS/Windows 布局。此项尚待用户验收。

## 多阶段与维护

无页面集成样例保存 CSV 的规格、输入与集成阶段；子节点依赖和父完成隐环由同一图校验器拒绝。工作台按获准节点绘制树，分页中不存在的父节点不会补出；隐藏前置只显示“有未公开前置条件”，不泄露标题、数量或状态。当前 GUI 创建单任务计划，可编辑已有完整计划中的节点文本；不提供图结构编辑器或 CSV 执行入口。

A 停服后备份到新目录，恢复时保留当前库副本。重新启动后，旧 token 失效，各端重新登录；任务版本与 grant 保留，曾被撤销的权限不得恢复。未知备份/schema 应拒绝，当前目录保持不变。保管恢复凭证和备份，不在共享聊天中传递。

## 自动化证据与产品边界

`apps/desktop-host/tests/organization-workgraph.spec.ts` 覆盖真实 Loader、HTTPS、两个原生身份、版本冲突、Session JSONL 冷读、独立账号绑定、撤权、CSV 裁剪及 SQLite/备份恢复。`organization-integration-built-smoke.mjs` 在普通 Node 和 Electron Node mode 启动私有组织进程与测试 Loader 子进程，通过生产私有 IPC 消费者验证上下文绑定、重开和撤权；不会创建窗口。

内部 Phase 7–8 完成后停止。本期只有任务定义、显式查看授权和本人预执行上下文。批准下发、员工接受/委托、运行、提交、完成、验收返工及实际产物访问仍属于后续产品 Phase 6–7A，不能通过伪造命令、模拟完成或直接改库替代产品验收。
