# 个人任务拆分界面优化

ui-personal-workflow 负责计划入口、审核与编辑、输入框任务增强开关、执行选择与控制、强制拆分测试设置。相关视图复用 ui-primitives 的按钮、图标、开关和弹窗，并使用应用主题变量。

计划弹窗按计划选择、版本审核、任务结构和任务详情组织内容。任务树与阶段条目共享选中任务，状态同时使用文字与颜色表示。详情分别展示验收条件、产物声明、执行证据和去重后的关联对话。窄窗口中任务结构与详情上下排列。

执行弹窗区分任务摘要、推进方式、预算和运行控制，展示动作与轮次预算的使用进度。核对动作、接力记录和执行证据独立分组。输入框入口与设置控件采用一致的字号、间距和状态样式。审核、保存、绑定、暂停、恢复和接力仍通过原有 Host 回调执行。

验证使用聚焦组件测试、TypeScript、局部 lint、文案门禁与客户端包构建。按用户要求不启动 Desktop 或浏览器；可见验收由用户执行。
